# WoWS Random Defense

함선을 건조·조합하며 적 함대의 50웨이브를 막는 비공식 팬 게임이에요.
현재 버전은 **v0.1.0-alpha**, Windows x64 테스트 배포예요.

## 다운로드와 실행

[Releases](https://github.com/Ch0m1n/WoWS-Random-Defense/releases)에서
`WoWS-Random-Defense-v0.1.0-alpha-Windows.zip`을 받아 압축을 풀고 **Play.cmd**를 실행해 주세요.

- 첫 실행: 에셋 ZIP 두 개를 자동 다운로드 → SHA-256 검사 → 자동 압축 해제
- 이후 실행: 설치된 같은 버전 에셋을 사용하며 오프라인 실행 가능
- 캐시 위치: `%LOCALAPPDATA%\WoWSRandomDefense\assets`
- 실행용 ZIP 약 81MB, 추가 다운로드 약 1.05GB. 설치·임시 압축 해제 공간으로 여유 공간 3GB 이상을 준비해 주세요.
- Godot 편집기나 PowerShell 7을 별도로 설치할 필요는 없어요.

이 저장소에는 배포 안내와 릴리스 파일만 올려요. 개발 프로젝트·추출 원본·편집 도구는 포함하지 않아요.

## 알파 테스트 범위

함선별 무장·탄종·화재·침수, 자동 능력, 건조·조합·연구, 1–4배속, 전투 결과 통계를 제공해요.
함장 초상화는 10명을 선택할 수 있지만 신규 7명은 아직 추가 능력이 없어요.
국적별 함장 재능은 설계 단계이며 이번 버전에는 적용되지 않았어요.
성능과 밸런스는 계속 조정 중이에요. 저사양 PC의 원활한 실행은 아직 검증하지 못했어요.

버그를 제보할 때 버전, 발생 상황, 스크린샷, 재현 방법을 함께 알려주세요.

## 권리와 고지

Wargaming과 제휴·후원·공식 승인을 받은 제품이 아닌 비공식 팬 프로젝트예요.
World of Warships 및 원작의 모델·이미지 등은 각 권리자에게 권리가 있어요.
이 저장소는 해당 에셋의 별도 재배포 라이선스를 부여하지 않아요.
공개 배포에 필요한 권리 확인은 별도로 필요해요.

Godot Engine 4.6.1 런타임은 MIT 라이선스로 제공되며 배포 ZIP에 라이선스와 제3자 고지를 동봉해요.
