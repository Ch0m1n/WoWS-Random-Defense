# WoWS Random Defense

함선을 건조·조합하며 적 함대의 50웨이브를 막는 비공식 팬 게임이에요.
현재 배포 버전은 **v0.1.2**, Windows x64용이에요.

## 다운로드와 실행

[최신 배포판 다운로드](https://github.com/Ch0m1n/WoWS-Random-Defense/releases/latest)

1. `WoWS-Random-Defense-v0.1.2-Windows.zip`을 내려받아요.
2. 압축을 전부 풀고 **Play.cmd**를 실행해요.
3. 첫 실행은 다운로드 비율·용량·속도·예상 남은 시간을 표시하며, 설치가 끝나면 게임이 열려요.

업데이트할 때도 새 ZIP을 별도 폴더에 전부 풀고 새 폴더의 Play.cmd를 실행해 주세요.
이전 폴더의 Play.cmd를 실행하면 이전 버전이 열려요.

실행 ZIP 약 84MB, 추가 다운로드 약 1.05GB예요.
Windows 10/11 x64와 여유 공간 3GB 이상을 준비해 주세요.
Godot 편집기나 PowerShell 7을 별도로 설치할 필요는 없어요.

에셋은 SHA-256 검사 후 자동으로 압축 해제하고
`%LOCALAPPDATA%\WoWSRandomDefense\assets`에 보관해요.
같은 에셋이 설치되어 있으면 다시 다운로드하지 않으며 오프라인 실행도 가능해요.
v0.1.2은 앞선 알파의 모델·텍스처·캐시를 그대로 재사용해요.
공유 에셋은 이전 알파 릴리스의 고정 다운로드 주소에 유지해요.

이 저장소에는 배포 안내와 릴리스 파일만 올려요.
개발 프로젝트·추출 원본·편집 도구는 포함하지 않아요.

## 플레이 기능

- 함선별 무장·탄종·관통·화재·침수와 자동 특수능력
- 건조·조합·연구, 1–4배속, 전투 결과 통계와 F3 실시간 딜량·점유율
- 포성·어뢰·피격·격침·알림 효과음 및 바다 환경음, 별도 음량 조절
- 10웨이브마다 열리는 특수 해역: 강화 보스·수반함과 단계별 자원·함선 선택권
- 전설 함장 10명의 공통 버프와 국적별 재능
- 지원 능력 40척 배정 및 등급별 효과 강화, 동종 지원 중첩 방지
- 이미지 카드·검색·함종 필터가 있는 전용 선택권 교환 화면
- 선체/상부구조물 장갑, 넓어진 적 진형과 중후반 체력·어뢰 밸런스 조정

영연방 함선이 아직 없어 콜린스는 공통 버프만 실전 적용돼요. 배경음악은 아직 없어요.
부위 장갑은 명중 후 확률 배분이며, 모델 부위별 실제 충돌 판정은 아니에요.
이번 변경을 포함한 자연 플레이 50웨이브 전체 균형은 추가 테스트가 필요해요.
성능·밸런스는 계속 조정 중이고 저사양 PC의 원활한 실행은 아직 검증하지 못했어요.
버그 제보 시 버전, 발생 상황, 스크린샷과 재현 방법을 함께 알려주세요.

## 권리와 고지

Wargaming과 제휴·후원·공식 승인을 받은 제품이 아닌 비공식 팬 프로젝트예요.
World of Warships 및 원작의 모델·이미지 등은 각 권리자에게 권리가 있어요.
이 저장소는 해당 에셋의 별도 재배포 라이선스를 부여하지 않아요.

Godot Engine 4.6.1 런타임은 MIT 라이선스로 제공되며 배포 ZIP에 라이선스와 제3자 고지를 동봉해요.
