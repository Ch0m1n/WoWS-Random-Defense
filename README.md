# WoWS Random Defense

함선을 건조·조합하여 50웨이브를 방어하는 Windows 10/11 x64용 비공식 팬 게임입니다.

## 다운로드 및 실행

[최신 버전 다운로드](https://github.com/Ch0m1n/WoWS-Random-Defense/releases/latest)

1. Windows ZIP을 새 폴더에 전체 압축 해제합니다.
2. **WoWSRandomDefense.exe**를 실행합니다.
3. 첫 실행 시 추가 에셋을 다운로드한 후 게임을 시작합니다.

실행 ZIP은 약 84MB, 추가 다운로드는 약 1.3GB입니다. Godot 편집기는 필요하지 않습니다.

**v0.1.7 이하 사용자는 이번에 새 ZIP을 직접 받아야 합니다.** v0.1.7.01부터 네 자리 패치 버전을 인식합니다. 이후 실행 시 업데이트를 확인합니다.

## 주요 기능

- 함선 건조·조합·연구, 자동 능력, 집중 공격, 특수 해역 보스
- 조합 즐겨찾기·검색·필터, 1~4배속
- F3 전투 통계, 최근 기록 조회 및 JSON 내보내기

v0.1.7.01에서는 일반 적 최종 체력을 같은 함종·티어 기준 1웨이브의 55배로 조정하고, 함선 능력·소나·연막·편의 기능을 확장했습니다. 상세 변경은 릴리스 노트를 참고하시기 바랍니다.

## 기록 및 삭제

전투 종료와 정상적인 게임 종료 시 기록을 자동 저장합니다. 강제 종료 시에는 저장되지 않을 수 있습니다.

완전 삭제는 게임 종료 후 **Uninstall.cmd**를 실행합니다. 삭제 목록을 확인하고 `DELETE`를 입력하면 게임 파일·에셋·설정·전투 기록을 삭제합니다. 사용자 추가 파일은 보존합니다.

버그 제보 시 버전·재현 방법·스크린샷 또는 전투 JSON을 첨부해 주시기 바랍니다.

## 고지

이 저장소는 배포 전용입니다. 개발 프로젝트와 추출 원본은 포함하지 않습니다.

Wargaming과 제휴하거나 공식 승인을 받은 제품이 아닙니다. 원작 모델·이미지 등의 권리는 각 권리자에게 있습니다. Godot 런타임의 MIT 라이선스 및 제3자 고지는 배포 ZIP에 동봉합니다.
